# ESP32-CAM BLE iOS

Система для бездротового керування камерою ESP32-CAM з iPhone через Bluetooth Low Energy (BLE). Без Wi-Fi, без сервера — пряме підключення телефону до модуля.

## Як це працює

```
iPhone (iOS App) ←──── BLE ────→ ESP32-CAM
```

- ESP32-CAM рекламує BLE-сервіс і чекає на підключення
- iOS-додаток знаходить пристрій, підключається, відправляє команди
- Фото передається по BLE чанками (по 200 байт) з flow-control
- ESP32 вміє йти в Deep Sleep і прокидатись за таймером

## Прошивка ESP32

### Що потрібно

- Arduino IDE або PlatformIO
- Плата: **ESP32-CAM AI-Thinker** (з PSRAM)
- Програматор: USB-TTL (FTDI/CP2102) або ESP32-CAM-MB

### Бібліотеки

Встанови через Arduino IDE → Boards Manager:
- `esp32` від Espressif (версія 2.x)

BLE-бібліотеки (`BLEDevice`, `BLEServer`, `BLE2902`) входять до складу esp32 core — окремо встановлювати не потрібно.

### Завантаження прошивки

1. Відкрий `esp32-scatch/CameraWebServer.ino` в Arduino IDE
2. Налаштування:
   - **Board**: `AI Thinker ESP32-CAM`
   - **Partition Scheme**: `Huge APP (3MB No OTA/1MB SPIFFS)`
   - **Upload Speed**: `115200`
3. Перед завантаженням з'єднай `IO0 → GND` (режим прошивки)
4. Натисни **Upload**
5. Після завантаження від'єднай `IO0 від GND` і натисни **Reset**

### Перевірка

Відкрий Serial Monitor (115200 baud). Після старту побачиш:
```
ESP32-CAM BLE Mode
PSRAM found: XXXXXXXX bytes free
BLE: Advertising started, waiting for iPhone...
```

## iOS-додаток

### Вимоги

- Xcode 15+
- iOS 16+
- Реальний пристрій (BLE не працює в симуляторі)
- Apple Developer Account (безкоштовний достатній для тесту)

### Запуск

1. Відкрий `ESP32CamApp/ESP32CamApp.xcodeproj` в Xcode
2. Вибери свій Target → Signing & Capabilities → вкажи свій Team
3. Підключи iPhone, вибери його як destination
4. Build & Run (`⌘R`)

### Можливості

**Підключення**
- Автоматичний пошук ESP32-CAM при відкритті додатку
- Відображення стану BLE та сили сигналу (RSSI) у режимі реального часу
- Автоматичне перепідключення при розриві зв'язку

**Зйомка**
- Кнопка **«Фото»** — зробити нове фото з увімкненим flash (якщо є)
- Кнопка **«Збережене»** — завантажити останнє фото з пам'яті ESP32
- Progress bar з відсотком та розміром під час завантаження
- Кнопка **«Скасувати»** — зупинити завантаження

**Перегляд та збереження**
- Превʼю фото одразу після завантаження
- Кнопка Share — зберегти у Фото або відправити через стандартний iOS Share Sheet

**Налаштування (через шестерню ⚙️)**

| Параметр | Діапазон | Опис |
|---|---|---|
| Роздільність | QQVGA (160×120) … QXGA (2048×1536) | Розмір кадру камери |
| Яскравість спалаху | 0–255 | Рівень підсвічування LED під час зйомки |
| Deep Sleep інтервал | 1–168 год | Через скільки годин ESP32 прокидається |
| Час очікування | 1–60 хв | Скільки хвилин ESP32 чекає на підключення перед сном |

**Інформаційна панель**
- BLE RSSI (дБм)
- Вільна PSRAM на ESP32
- Розмір останнього фото
- Час роботи ESP32 з моменту запуску

## Deep Sleep

ESP32-CAM підтримує режим Deep Sleep для економії енергії:

- При запуску чекає `awakeMinutes` хвилин (за замовчуванням 5) на BLE-підключення
- Якщо iPhone не підключився — засинає на `sleepHours` годин (за замовчуванням 24)
- Параметри сну зберігаються в RTC-пам'яті й переживають перезавантаження

## BLE-протокол

| UUID | Напрямок | Призначення |
|---|---|---|
| `...0002` | Write | Команди (`capture`, `saved`, `send`, `next`, `flash:N`, `framesize:N`, `sleep:N`, `awake:N`) |
| `...0003` | Notify | Розмір фото (4 байти uint32) |
| `...0004` | Notify | Дані фото (чанки по 200 байт) |
| `...0005` | Notify | JSON-статус пристрою |
